# Release identity and reproduction

Every file in this directory was generated by a single tagged release of
this repository. Use the identity below when citing or re-running these
results.

| Field | Value |
|---|---|
| Repository | governance-drift-toolkit |
| Release tag | v0.5.0 |
| Concept DOI | [10.5281/zenodo.19236417](https://doi.org/10.5281/zenodo.19236417) (always resolves to the latest release) |
| Version DOI | pending; recorded once the Zenodo archive for this tag is minted |
| Entry point | `examples/ieee_cis_robustness.py` |
| Companion entry point | `examples/ieee_cis_simulator_sensitivity.py` in evidence-sufficiency-calc v0.4.0 or later |

The v0.3.0 and v0.3.1 archives do not reproduce the numbers below. Both were produced before
imputation statistics were fitted on the reference window and before reference F1 was estimated
out-of-sample, so their results reflect a calibration that used future-window information. Cite
this tag for the values in this directory.

## Environment

Python 3.14.5, numpy 2.4.3, pandas 2.3.3, scikit-learn 1.8.0, scipy 1.17.1,
drift 0.5.0 (this package at this release).

## Data

IEEE-CIS Fraud Detection, Kaggle competition `ieee-fraud-detection`, file
`train_transaction.csv` only (590,540 transactions, 182 days of
`TransactionDT` coverage). The dataset is not redistributed here; see
`examples/ieee_cis_demo.py` for the download instructions. The 56 numeric
features used are listed in that file's `FEATURE_COLS` and are
median-imputed per column.

## Commands

```bash
pip install -e ".[demo]"
python examples/ieee_cis_robustness.py
```

Determinism: model fitting uses `random_state=42`; drift injection uses
numpy `default_rng` seeds 42, 7, and 2026 (seed variation is itself one of
the reported variants). Re-running the entry point on the same data and
environment reproduces every file in this directory byte for byte.

The `environment.git_head` field inside `variants_summary.json` records the
commit that was checked out when the results were generated, which is the
parent of the release commit that publishes the runner. The authoritative
code identity for these results is the release tag above.

Before any variant runs, the script asserts a reproduction guard: the base
configuration must reproduce the `ieee_cis_demo.py` detection counts and
Window 5 values exactly, or the run aborts.

## Files

| File | Contents |
|---|---|
| `SUMMARY.md` | Human-readable results: detection counts per variant, component attribution, shared-component quantification, last-window values, simulator checkpoints |
| `variants_summary.json` | Machine-readable per-variant results for the full grid, plus the recorded environment |
| `signals_<config>.json` | Raw per-window signals for one (window scheme, model class, seed) configuration; every weight, threshold, and ablation variant is re-aggregated from these tables |

Configurations: `base_30d_logreg_s42` (base), `win15_logreg_s42`,
`win45_logreg_s42`, `overlap30x15_logreg_s42`, `base_30d_hgb_s42`
(second model class), `base_30d_logreg_s7`, `base_30d_logreg_s2026`.
